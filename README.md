# Amia-plugin-meme

Mizuki Bot 的中文表情包图库、随机发送和分类管理插件，适配 NoneBot2 / OneBot V11，并向 PicMenu Next 提供普通用户菜单。

## 普通用户功能

```text
表情帮助 / 表情包帮助 / meme帮助
表情列表 / 表情包列表 / 图库列表
随机表情 / 随机meme / 随机图片 / 随一张
发送 <文件夹名>
查看 <图片名>
看所有 <文件夹名>
<文件夹名> 上传（附带图片或回复 ZIP）
```

PicMenu 默认只展示以下 6 类中文功能：

1. 表情列表；
2. 随机表情；
3. 分类发送；
4. 查看图片；
5. 分类预览；
6. 上传表情。

最近上传、删除、溯源、锁定和屏蔽群等管理功能保留在代码中，但不会出现在普通用户默认菜单里。

## 管理边界

- `删除 <图片名>`：删除图片并清理记录；
- `溯源 <图片名>`：查看上传记录；
- `锁定/解锁 <文件夹名>`：控制分类写入；
- `屏蔽群/解除屏蔽 <群号>`：控制群级访问；
- 管理命令必须继续受现有权限判断约束，不能只依赖菜单隐藏。

## 数据目录

运行时图库位于插件目录下的 `meme/`，上传记录位于 `image_info.json`。数据库可以使用配置中的 MySQL 连接信息。

以下内容属于运行数据，不提交到 Git：

```text
meme/
image_info.json
data/
runtime/
logs/
*.db *.sqlite *.log
```

图片和 ZIP 上传必须经过现有路径、扩展名和权限检查。不要把 Token、数据库凭据、真实聊天记录或来源不明的受版权保护素材提交到仓库。

## 测试

```powershell
python -m unittest discover -s tests -v
python -m compileall -q .
git diff --check
```

离线测试只覆盖加载和 Release010 最低烟雾路径。真实 MySQL、真实图库、群权限、ZIP 上传、删除和 QQ 图片展示未执行时必须记录为 `NOT RUN`。
